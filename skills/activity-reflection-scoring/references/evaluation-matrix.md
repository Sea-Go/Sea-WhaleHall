# 评测矩阵（运行时资料）

以下矩阵用于维护运行时评分 Skill 与表驱动测试。每次修改公式、中文提示或输出契约，都要覆盖这些维度。

| 维度 | 最小覆盖 | 期望 |
| --- | --- | --- |
| 目标相关性 | `direct`、`supporting`、`unrelated`、`uncertain`、无目标 | 前两类按系数计算；后三类为零。 |
| 证据 | 强交叉、受支持、弱 | 系数依次为 `1.00`、`0.70`、`0`。 |
| 时长 | `≥120 秒`、`30–119 秒`、`<30 秒`、未知 | 系数依次为 `1.00`、`0.75`、`0.50`、`0.50`。 |
| 置信度 | 确定、推测、不确定 | 确定使用原值；推测封顶 `0.85`；不确定为零。 |
| 零分边界 | 状态、未知、低交互、信息缺失、敏感交易 | 事件不贡献分数，状态事件仍可保留在事件流。 |
| 混合窗口 | 有效活动与状态/零分活动并存 | 只累计有效活动，窗口总分封顶 `1.00`。 |
| 累计与消费 | 两个 `0.60` 回执 | 账本累计 `1.20`，只建立一个串行 job，成功后按 job 的精确 `consumedScore` 扣除。 |
| 隐私 | 含 URL、应用名、文档内容、联系人或账号的 reason | 输出必须脱敏成简短中文，分数值不被客户端改写。 |

真实端到端验证只允许使用脱敏 synthetic window。检查返回分数能直接进入测试账本、GPU 未被 relay 占用，并且原始活动记录不出现在日志、测试快照或仓库中。
