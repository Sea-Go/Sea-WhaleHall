# 状态、活动与时间片参考（运行时资料）

## 六维判断顺序

| 维度 | 可用结论 | 使用限制 |
| --- | --- | --- |
| 观测质量 | 有内容证据、仅元数据、输入稀少、信息缺失、权限边界 | 没有输入的内容不得补全；权限不足只说明边界，不猜测活动。 |
| 在场状态 | 正常、暂离开始、恢复活动、锁屏、解锁、睡眠、唤醒 | 真实 presence 边界由客户端生成零分 `idle_transition`，模型不输出。 |
| 交互密度 | 连续创建、连续操作、轻度导航、阅读候选、低交互、无可用交互 | 低交互只能支持“不确定：”，不能确认正在阅读或工作。 |
| 连续性 | 新活动、持续活动、短暂辅助切换、明确主题切换、中断、恢复 | 前台/标签变化不是自动拆段理由。 |
| 人类活动 | 12 个内部枚举之一 | action 使用中文人类活动描述，而非应用、字段或传感器名称。 |
| 评分资格 | 目标直接相关、支持目标、无关、不确定、状态/敏感活动 | 只判断资格；具体分数交给独立评分 Skill。 |

## 12 类活动情境

| 内部枚举 | 细分情境 | 可核对中文 action 示例 | 必须避免 |
| --- | --- | --- | --- |
| `development` | 编写、调试、测试、审阅、重构、配置 | 推测：正在编写代码；推测：正在调试或测试程序 | 代码、仓库、路径、编辑器名称、具体报错。 |
| `writing` | 撰写、修改、校对 | 推测：正在撰写或修改文本 | 正文、收件人、文档标题。 |
| `research` | 搜索、阅读、比较、技术资料查阅 | 推测：正在查阅技术资料 | URL、搜索词、网页标题。 |
| `communication` | 撰写、阅读或回复消息，会议或通话 | 推测：正在进行沟通 | 联系人、群组、会议主题、消息内容。 |
| `planning` | 目标梳理、任务清单、日程安排、计划调整 | 推测：正在规划安排 | 任务名称、日历标题、具体日程。 |
| `data_work` | 表格编辑、筛选、图表、仪表盘、数据查询 | 推测：正在处理数据 | 表格值、字段、业务数据。 |
| `media` | 持续观看或收听、媒体页面浏览 | 推测：正在观看或收听媒体内容 | 节目、作者、媒体标题。 |
| `gaming` | 持续操作游戏、菜单/启动器、游戏直播 | 确定：正在进行游戏（仅有游戏上下文与持续操作时） | 游戏名称、账号、对局信息。 |
| `system_file_ops` | 整理文件、系统设置、安装更新、应用管理 | 推测：正在整理文件或调整系统设置 | 路径、文件名、软件名、配置详情。 |
| `commerce` | 商品浏览或比较、购物车、结算、支付、账户与金融页面 | 推测：正在浏览商品或比较信息；不确定：正在处理敏感页面，具体活动无法判断 | 商品名、订单、金额、账户、支付与金融细节。 |
| `idle_transition` | 暂离、恢复、锁屏、解锁、睡眠、唤醒 | 客户端确定性生成，例如：确定：电脑已锁屏 | 模型猜测、人工活动结论、任何分数。 |
| `other_unknown` | 未知应用、矛盾证据、只有切换/输入统计 | 不确定：当前活动无法判断 | 把未知内容确定为阅读、工作或娱乐。 |

## 聚合与时间片

1. 连续的编辑、输入、终端和资料查阅若服务同一目标，合并为一个事件。
2. 只有持续且可核对的主题改变才拆分事件；短暂辅助切换不拆段。
3. 模型给出完整且有效的短时间片时直接保留；只有时间端点缺失时才按相邻已知边界或窗口边界补齐。
4. 重叠的同类描述只能保留最具体且不泄露信息的 action，并取其可确认时间的并集。
5. 暂离、锁屏、睡眠等边界可以和有效活动同窗存在，但它们是单独的零分状态事件。
