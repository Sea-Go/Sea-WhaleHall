# 评分规则（运行时资料）

## 窗口分数

评分对象是封闭窗口中的语义活动事件，而不是原始观察。模型在内部逐事件计算：

```text
事件贡献 = 相关性系数 × 证据系数 × 时长系数 × 置信度系数
窗口 score = min(1, 所有事件贡献之和四舍五入到两位小数)
```

窗口 `score` 是本地账本可直接累计的贡献，不是立即调用 Agent 的命令。

| 项目 | 规则 |
| --- | --- |
| 相关性 | `direct=1.00`；`supporting=0.60`；`unrelated=0`；`uncertain=0`。没有当前目标时不按目标过滤：持续、可核对的活动一律按 `supporting=0.60` 计。 |
| 证据 | 强交叉证据 `1.00`；受支持证据 `0.70`；仅单一弱观察 `0`。 |
| 时长 | `≥120 秒=1.00`；`30–119 秒=0.75`；`<30 秒=0.50`；无法确认时间 `0.50`。 |
| 置信度 | `确定：` 使用 `confidence`；`推测：` 使用 `min(confidence, 0.85)`；`不确定：` 固定 `0`。 |

## 证据强度

- **强交叉证据**：至少两类独立且相互支持的信号，其中至少一类能说明具体活动。例如“文档修改 + 持续输入”或“游戏上下文 + 持续操作”。
- **受支持证据**：有活动特定证据，但缺少第二类直接交叉支持。
- **弱证据**：只有前台切换、标签导航、输入统计、低交互、未知应用，或信息相互矛盾。弱证据不得累计分数。

## 没有当前目标时

没有当前目标时不判断目标相关性：持续、可核对的有效活动一律填 `goal_relevance=supporting`，按 `0.60` 计入公式；证据、时长与置信度照常判断。敏感支付、账户、结算页面，状态事件，未知或不确定活动仍为 `0`，填 `uncertain`。没有当前目标时不得填 `direct` 或 `unrelated`。

## 固定零分条件

以下任一情况的事件贡献为 `0`：状态事件、`idle_transition`、`other_unknown`、低交互、证据缺失、证据矛盾、`goal_relevance=unrelated/uncertain`、不确定 action、敏感支付、账户、结算或金融交易页面。

有当前目标时，普通商品比较只有在目标直接相关且证据充分时才可以计分；没有当前目标时它与其他活动相同。它不能因为停留时长或输入次数而自动计分。

## 校准示例

- 目标直接相关、持续 3 分钟、强交叉证据、`推测：`、`confidence=0.85`：`1 × 1 × 1 × 0.85 = 0.85`。
- 支持目标、持续 90 秒、强交叉证据、`推测：`、`confidence=0.75`：`0.60 × 1 × 0.75 × 0.75 = 0.34`。
- 目标直接相关、持续 20 秒、受支持证据、`推测：`、`confidence=0.60`：`1 × 0.70 × 0.50 × 0.60 = 0.21`。
- 没有当前目标、持续 3 分钟、强交叉证据、`推测：`、`confidence=0.85`：`0.60 × 1 × 1 × 0.85 = 0.51`。
- 锁屏、暂离、睡眠、未知活动或敏感结算：`0`。
- 多段有效活动相加超过 `1`：窗口 score 固定为 `1.00`。

`score_reason` 示例：`目标直接相关，强交叉证据，持续约 3 分钟，计 0.85 分。`或`没有当前目标，持续撰写约 3 分钟，强交叉证据，计 0.51 分。`
