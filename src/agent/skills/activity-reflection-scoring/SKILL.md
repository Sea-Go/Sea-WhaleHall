# 活动反思评分

先聚合语义活动事件，再计算本窗口可累计的 `score`。它不是调用下一步 Agent 的命令；客户端只校验格式、范围、空事件为零和隐私边界，不重算或覆盖模型分数。

## 唯一公式

`事件贡献 = 相关性 × 证据 × 时长 × 置信度`，`score = min(1, 所有事件贡献之和四舍五入到两位小数)`。

- 相关性：`direct=1.00`，`supporting=0.60`，`uncertain=0.60`，`unrelated=0`。`uncertain` 表示活动明确，但看不出它与当前目标的关系，按 `supporting` 计；`unrelated` 表示明确与目标无关。没有当前目标时不按目标过滤：持续、可核对的活动一律按 `supporting` 计，并填 `goal_relevance=supporting`（不得填 `direct` 或 `unrelated`）。
- 证据：强交叉 `1.00`，指至少两类独立且相互支持的信号，且至少一类能说明具体活动，如“文档修改 + 持续输入”“游戏上下文 + 持续操作”；受支持 `0.70`，指有活动特定证据，但缺少第二类直接交叉支持；单一弱观察 `0`，指只有前台切换、标签导航、输入统计、低交互、未知应用或相互矛盾的信息。
- 时长：不少于 120 秒 `1.00`，30–119 秒 `0.75`，少于 30 秒或未知 `0.50`。
- 置信度：`确定：`取 `confidence`；`推测：`取 `min(confidence, 0.85)`；`不确定：`为 `0`。

状态、未知、低交互、证据缺失或矛盾、普通切换/导航/输入统计、与目标明确无关、敏感支付/账户/结算/金融活动均为零分；没有当前目标时这些零分条件照常生效。`uncertain` 只放宽相关性这一项：活动本身无法确定（以“不确定：”开头）的事件仍然为零分。有当前目标时，普通商品比较只有在目标直接相关、证据充分时才可能计分，不能因停留时长或输入次数自动计分。不得按观察数、应用数或拆分连续活动抬高分数。

`score_reason` 用简短中文说明相关性、证据、时长与分数，且不含应用名、内容、URL、联系人、账号、金额或原始字段。例如：“目标直接相关，强交叉证据，持续约 3 分钟，计 0.85 分。”或“与目标的关系无法确认，按支持目标计，强交叉证据，持续约 5 分钟，计 0.42 分。”或“没有当前目标，持续撰写约 3 分钟，强交叉证据，计 0.51 分。”
